# Future Feature Considerations

Inspired by weenote.kr (South Korean school counselling SaaS). These are not scheduled — logged here so future Claude instances have context when the user asks to build them. Map everything to NZ clinical context (NHI, ACC, MOE compliance) rather than Korean equivalents (NEIS).

| Feature | Notes |
|---|---|
| **Activity Log** | Dedicated audit trail of all clinical actions per client — session counts, contact types, referrals made. More granular than the current WeeklySummary analytics. |
| **Group Management** | Group session workflows: group calendar events exist (`category='group'`) but there's no page for managing group cohorts, attendance, or group session notes. |
| **Crisis Management** | Dedicated crisis workflow beyond the current `clinical_alert` flag — structured risk assessment forms, safety plan builder, escalation tracking, and crisis contact logging. |
| **Programs / Treatment Plans** | Structured treatment pathways: goals, milestones, review dates, linked sessions. Currently sessions are standalone with no overarching treatment plan object. |
| **Psychological Assessments** | Standardised tool scoring (PHQ-9, GAD-7, K10, DASS-21 etc.) stored per client with trend charting over time. NZ ACC and DHB reporting often requires these scores. |
| **Genogram** | Interactive family/relationship map builder linked to a client record. Useful for systemic and family therapy contexts. |
| **Form Management** | Beyond the current document template registry — dynamic fillable forms that save structured data back to the DB (consent forms, intake questionnaires, referral letters). |
| **Standalone Notes** | Quick freeform notes not tied to a session — phone call logs, collateral contact notes, brief observations between sessions. |
| **MOE / DHB Reporting Export** | NZ equivalent of NEIS — anonymised aggregate CSV exports formatted for Ministry of Education or DHB statistical reporting requirements. |
| **Team Activity XLSX Export** | Per-counsellor XLSX export designed for team-level analysis (AUT, UoA, Emerge Aotearoa, DHB teams etc). Counsellors export individually and combine via SharePoint/Excel. Columns: `Counsellor`, `Session Date`, `Client ID`, `Session #`, `High Watch` (boolean — high-risk/suicidal ideation flag, counsellor-set, never AI-inferred), `Session Summary` (2–3 sentence AI digest, generated from `soap_subjective` only — never from `counsellor_private_notes`), `Category` (AI-suggested from the summary, counsellor can edit; list is org-configurable — default list: Anxiety/Stress, Depression/Low Mood, Academic/Study, Housing/Financial, Relationships/Whānau, Identity/Culture, Crisis/Safety, Grief/Loss, Career/Future, Other). **DB columns needed on `sessions` table:** `session_summary TEXT`, `session_category TEXT` (comma-separated tags), `high_watch INTEGER DEFAULT 0`. Summary generated (and stored) when counsellor marks session complete, not at export time — export is instant read from DB. No client name in the export — Client ID only, for safe team-level sharing. |
| **Session Notes Output Format Picker** | When AI generates structured notes, offer format options: wide single summary, key findings bullets, 4-section grid, or table layout. |
| **Audio Dual-Stream Capture** | **Implemented** — see Audio Recording section in CLAUDE.md. |
| **Auto-delete audio after transcription** | After `model.transcribe()` succeeds in `transcribe.py`, call `os.unlink(audio_path)`. Keep `_transcript.txt` only. Prevents backup ZIPs growing to gigabytes. Only delete on success — if Whisper throws, keep the audio so the counsellor can retry. One-line change. |
| **USB Export Button (Option B)** | "Export to USB" button on `BackupPage` — Electron `dialog.showOpenDialog` folder picker, app copies latest backup ZIP to chosen drive. "Open Folder" button already exists as manual workaround. |
| **Auto-Update (electron-updater)** | **FULLY WIRED (2026-06-05).** Releases repo: `LeConsulat2/private-workspace-releases`. To ship: bump `"version"` in `package.json`, run `$env:GH_TOKEN="token"; npm run dist:publish`. Existing installs auto-update silently. Never bundle `.gguf` weights in payload. Code signing (OV cert) needed before serious paid distribution. |
| **Distribution Pipeline** | Stripe → `checkout.session.completed` webhook → Supabase Edge Function → generate 16-char license key → Resend email (key + download link). Installer on Cloudflare R2 or GitHub Releases. `purchases` table: `stripe_session_id`, `customer_email`, `license_key`, `workspace_type`, `max_devices`, `purchased_at`. |
| **License Device-Transfer Policy (undecided — 2026-06-05)** | Self-service deactivation removed from UI. Options: (A) support-only forever; (B) rate-limit detection server-side (N deactivate+reactivate in 30 days → flag); (C) name-mismatch warning on activation. Option B or C would allow re-adding self-service deactivate to UI. Decision pending. |
| **Network Activity Transparency Panel** | Settings section: "What leaves this device" — ✅ license key / version / installer download vs 🔒 client records / notes / audio (never). One-page PDF for IT/procurement. |
| **Template Export: AI Structure Reader** | Upgrade `_fill_value()` keyword matching in `exporters.py` — AI reads DOCX structure (field labels, table headers), maps session content to fields. DOCX only; PDF stays letterhead-overlay. |
| **AI Prompt Polish (pre-release)** | Target `backend/services/ai.py` prompt-building functions: (1) ACC/NHI/MOE framework refs in beautify + template-mapping prompts; (2) Te Whare Tapa Whā lens explicitly in `_build_beautify_messages` structured path; (3) tighten Risk Level guidance to name specific indicators. Goal: precision, not length. |
| **Image Analysis (OT / Art Therapy)** | Upload photo of client artwork → Gemma 4 multimodal describes clinical observations → feeds into session notes as draft observation block. Requires `POST /api/ai/analyze-image` + llama-server image content in messages array. Gemma 4 E4B/E2B support vision natively. Never auto-saves raw image to DB — text only. |
| **Bulk Dossier Export** | Loop all clients → zip of per-client chronological PDFs. Addresses the gap where counsellors must run dossier export per client for a complete data extract. |
